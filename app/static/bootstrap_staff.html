Crear cuenta de personal — GRIP

Solo funciona si la variable STAFF_BOOTSTRAP_SECRET está configurada en Railway. Úsala para crear las primeras cuentas y luego borra esa variable.

Una vez creadas las cuentas que necesitas, entra en Railway → Variables y borra STAFF_BOOTSTRAP_SECRET para cerrar esta puerta. Puedes volver a ponerla si necesitas crear más cuentas después.
